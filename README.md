# 金型まなびラボ（Kanagata Learning Lab）

製造業の「金型」を体系的に学べる、ビルド不要の静的 Web アプリです。
初心者・営業職・技術者のいずれもが、必要な深さで学べるように構成しています。

## 特徴

- **金型図鑑（12種類）** — プレス／射出成形／ダイカスト／鍛造／砂型鋳造／金型鋳造・低圧鋳造／ブロー成形／押出・引抜ダイ／圧縮成形・ゴム金型／粉末冶金／樹脂型・シリコーン型／3Dプリンタ活用。同じ切り口（原理・構造・型材と寿命・費用と納期・設計の勘所・代表的な不良）で横断比較できます。
- **図解** — プレス金型／射出成形金型の断面構造と、せん断面の構成を、番号コールアウト付きの SVG で解説。ライト／ダークどちらでも読めます。
- **計算ツール（7種）** — 工法比較の損益分岐点、成形収縮率からの型寸法、せん断クリアランス、90°曲げの展開長、必要型締力、冷却時間、抜き勾配とシボの影響。
- **用語集（152語）** — カテゴリ絞り込みとキーワード検索つき。
- **クイズ（71問）** — カテゴリ別出題、解説つき、間違えた問題の復習表示。

### 射出成形ラボ

- **射出成形のしくみ** — 成形機の1サイクル（型閉じ→射出→V/P切替→保圧→冷却・計量→型開き→突き出し）のアニメーション。スクリューの3区間・逆流防止リング・トグル機構の動きと、射出圧力／キャビティ内圧／スクリュー位置の波形を同期表示。肉厚断面の**ファウンテンフロー（噴水流）**と固化層のアニメーション、Cross-WLF モデルによる**粘度曲線**、冷却時間の式、条件出しの手順。
- **樹脂流動シミュレーター** — ブラウザ内で動く 2.5D 充填解析。ゲート・ベントをクリックで配置し、材料（PP・ABS・PC・PA66・POM）と成形条件を変えて、充填パターン（等時間線）・圧力・樹脂温度・固化層を表示。ウェルド／メルドライン、エアトラップ（断熱圧縮の空気温度）、ショートショット、ランナーバランス、スパイラルフロー流動長を判定し、所見を文章で解説。射出時間を振って必要圧力の谷を探す**成形ウィンドウ**計算つき。7つのモデルと6つの演習。

#### シミュレーターの計算方法

| 項目 | 方法 |
| --- | --- |
| 流れ | Hele-Shaw 近似（流量は溶融層厚の3乗に比例）＋コントロールボリューム法。流動先端は p=0、ゲートは共通圧力 |
| 粘度 | Cross-WLF モデル＋Rabinowitsch 補正。流れが急変したステップは粘度を再評価して解き直す（ピカール反復） |
| 熱 | 風上順の陰的移流、せん断発熱（Q·Δp）、固化界面への熱損失 |
| 固化層 | 壁への伝導と溶融コアからの熱供給の収支（Stefan 型、陰解法） |
| 制御 | 設定流量で射出し、圧力上限・V/P切替（既定98%）で圧力制御へ |
| 線形ソルバー | 充填順に並べた未知数に MIC(0) 前処理＋デフレーション（2レベル）付き共役勾配法 |
| ウェルド | 平滑化した充填時刻の勾配から流動先端の向きを求め、互いに向き合い、かつゲートからの経路がかなり上流まで分かれている隣接セルの境界 |
| エアトラップ | 外周（PL）・ベントに通じない未充填領域。閉じ込めた空気は断熱圧縮して背圧に |

保圧・冷却・そり・繊維配向は計算しません。材料定数は汎用グレードを想定した代表値で、学習用に傾向をつかむためのものです。
- **サイト内横断検索**、ダークモード、スマートフォン対応。

## 学習の流れ

| 対象 | おすすめルート |
| --- | --- |
| はじめての方 | 金型とは何か → 金型の構造と部品 → 金型ができるまで → クイズ |
| 営業・非技術職 | 金型とは何か → コスト・見積・納期 → 金型図鑑（比較表） |
| 技術者・実務者 | 金型図鑑 → 型材・熱処理・表面処理 → 金型を削る技術 → 射出成形のしくみ → 樹脂流動シミュレーター → 不良とトラブル対応 → 計算ツール |

## ローカルで見る

依存パッケージもビルドも不要です。リポジトリを開いて `index.html` をブラウザで開くだけで動きます。

簡易サーバーで確認する場合:

```bash
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## GitHub Pages で公開する

**方法A（推奨・自動）**
リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定します。
`main` ブランチへの push で `.github/workflows/pages.yml` が動き、自動的に公開されます。

**方法B（ブランチ公開）**
Settings → Pages → Source を **Deploy from a branch** にし、対象ブランチと `/ (root)` を選びます。
Jekyll の処理を回避するための `.nojekyll` を同梱済みです。

解析エンジンは DOM に依存しないので、Node でもそのまま動かせます。

```js
global.window = { KANAGATA: {} };
['materials', 'models', 'flowsim'].forEach(f => require('./assets/js/sim/' + f + '.js'));
const K = window.KANAGATA, model = K.flowModelById('lid'), grid = K.rasterizeModel(model), mat = K.materialById('PP');
const sim = new K.FlowSim(grid, mat, { Tm: 230, Tw: 40, fillTime: 1.2, Pmax: 150e6,
  gates: model.gates.map(g => K.cellAt(grid, g[0], g[1])) });
while (!sim.done) sim.step();
console.log(sim.result.status, sim.result.Pmax / 1e6, 'MPa', sim.result.traps.length, 'air trap(s)');
```

フレームワークは使っていません。素の HTML / CSS / JavaScript のみで、
すべてのスクリプトは `window.KANAGATA` 名前空間にデータを足していく構成です。

## 内容を追加・修正するには

- **金型を追加する** — `assets/js/data/molds2.js` の `push(...)` に、既存エントリと同じキー（`id, name, en, cat, icon, oneLine, products, summary, structure, spec, points, troubles`）を持つオブジェクトを足します。図鑑一覧・比較表・トラブル表・サイト内検索には自動で反映されます。
- **読み物を追加する** — `topics` にキーを足し、`assets/js/app.js` 冒頭の `ROUTES` に1行追加します。本文中で `[[fig:pressDie]]` と書くと図版に展開されます。
- **用語・クイズを追加する** — それぞれのデータファイルに1行追加するだけです。件数表示は自動で更新されます。

## 数値の取り扱いについて

掲載している収縮率・クリアランス・型寿命・費用・納期などの数値は、いずれも広く使われている **一般的な目安** です。
実際の値は材料メーカー、設備、製品形状、社内標準によって変わります。
設計・見積の根拠には、必ず一次情報（材料メーカーの技術資料、設備仕様、社内実績データ）をご確認ください。
